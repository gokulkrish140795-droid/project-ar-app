# Project AR — UI Blueprint v2

## North star
Magical-phone cinematic UI. Characters and hologram own the frame. AAA bar on every element.

## Flow
`gateway → prank → video_montage → uncle_hologram → scavenger_hunt`

## Keep
Mini-Me / Ginger 3D + poses, wording, floo, trap No, heart-meter → kiss → montage.

## AAA bar
Typography, captions, panels, CTAs, meters, hologram, motion, spacing, FX.
No parchment cards, no wax scroll, no mouth bubble over Ginger, no square particle dust.
