# Reliquary Lens APK — Features (LOCKED v2)

**B = easy Unity / low risk. WOW = polish goal. Conflicts with older Grok chat use Gokul’s locks below.**

## B. Good features (build these)

1. **Wake the Lens** — Fogged glass; she **wipes with her finger**; app comes alive with name **Aishwarya**.  
2. **Home gold ring** — After wake, glowing gold ring on a surface (tap/place). Home base for vaults; she may leave it there.  
3. **Ring heartbeat** — Soft slow pulse while waiting.  
4. **Real shadows** under holograms so they feel planted in the room.  
5. **Room-matched lighting** — Dimmer/warmer in dim rooms; brighter in bright rooms (light sensor + Night Lens).  
6. **Vibration map** — Soft clicks on vault dials; thump on vault open; rising vibe on open-world finds; heartbeat pulse on **finale ring rise / Look up** (not Protocol 0510 — typing removed).  
7. **Ring persistence** — Home / Friends / Guardian Angel rings stay where placed; she can walk away and return.  
8. **Soft blur** behind menus and captions over camera.  
9. **Card seal** — Gold wax seal stamps on successful card scan before riddle.  
10. **Music-box vaults** — Each dial turn = one soft note; correct word = short melody (+ Latch Click / Velvet Pocket / Stairs Dust Drift).  
11. **Collection page** — Cards, riddles, letters found so far (scrapbook feel).  
12. **Hint** — After a delay, gentle hint so she never stays stuck.  
13. **Back** on every screen.  
14. **Chapter colour** — Gold → cyan → rose-gold as chapters progress.  
15. **Save progress** — App close / battery → resume where left off.  
16. **Rehearsal** — Gokul tests with **no PIN** (he stays nearby). Optional private jump UI later only if he asks — default = no secret PIN gate.  
17. **Night Lens** — Darker glowing look at night / low light.  
18. **Thermal / quality ease-off** — Smooth display; ease quality when tablet warms so it doesn’t stutter/overheat.  
19. **Open-world finds (v2)** — Two early hidden points (Friends + Guardian Angel): rising vibration + edge blink; she never sees markers; on lock, AR ring reveals.  
20. **Ring agency** — After find: leave / move / close / reopen Friends and Guardian Angel rings.
